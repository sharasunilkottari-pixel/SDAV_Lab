Binomial Distribution

Counting the number of successes in a fixed number of independent trials.

📖 What is this?

Imagine flipping a coin n times. Each flip is an independent trial with the same success probability p. The Binomial distribution tells you the probability of getting exactly k successes (heads) in those n flips.

Real example: In a class of 20 students, if each student has a 35% chance of passing a quiz, what's the probability that exactly 7 students pass?

🧭 How to use

  1. Set n (trials) and p (success chance).
  2. Click Update to refresh stats + chart.
  3. Read the 5 stat cards (mean, variance, …).
  4. Enter a k to compute P(X = k) or P(X ≤ k).
  5. Look at the chart — the dashed line marks the mean.

Probability Mass Function (PMF)

PMF answers: "What is the probability of getting exactly k successes?"

P(X = k) = C(n, k) · pk · (1−p)(n−k) C(n, k) is "n choose k" — the number of ways to pick k successes out of n trials.
Enter a value for k (0 ≤ k ≤ n) and click Calculate.

Cumulative Distribution Function (CDF)

CDF answers: "What is the probability of getting k or fewer successes?"

P(X ≤ k) = Σi=0k C(n, i) · pi · (1−p)(n−i) Add up all the individual probabilities from i = 0 up to i = k.
Enter a value for k (0 ≤ k ≤ n) and click Calculate CDF.
P(X ≤ k) = probability of getting k or fewer successes. The complement P(X > k) is shown alongside.

Poisson Distribution

Counting how many events happen in a fixed interval — when events are rare.

📖 What is this?

Suppose events happen randomly but at a steady average rate λ per interval (e.g. 5 emails per hour). The Poisson distribution gives the probability of observing exactly x events in one such interval.

Real example: A help desk gets an average of 5 calls per hour. What's the probability of getting exactly 2 calls in the next hour?

🧭 How to use

  1. Set λ — the average rate per interval.
  2. Set x — the count you want to test.
  3. Click Update to refresh stats + chart.
  4. Use the PMF section to find P(X = x).
  5. Use the CDF section to find P(X ≤ x).

Probability Mass Function (PMF)

Probability of observing exactly x events.

P(X = x) = (e−λ · λx) / x! e is Euler's number (≈ 2.718). The x! at the bottom is the factorial of x.
Enter a value for x (x ≥ 0) and click Calculate.

Cumulative Distribution Function (CDF)

Probability of observing x or fewer events.

P(X ≤ x) = Σi=0x (e−λ · λi) / i! Sum the individual PMF probabilities from 0 up to x.
Enter a value for x (x ≥ 0) and click Calculate CDF.
P(X ≤ x) = probability of observing x or fewer events. The complement is shown too.

Geometric Distribution

Counting how many trials are needed to get the first success.

📖 What is this?

Keep flipping a biased coin (success probability p) until you get heads for the first time. The Geometric distribution tells you the probability that the first success happens on the k-th trial.

Real example: A basketball player scores a free throw 35% of the time. What's the chance their first successful shot is on the 3rd attempt?

🧭 How to use

  1. Set p — the success chance per trial (0 < p ≤ 1).
  2. Click Update to refresh stats + chart.
  3. Enter k to compute P(X = k) — first success on the k-th trial.
  4. Use the CDF section for P(X ≤ k) — first success on or before the k-th trial.
  5. Notice: smaller p ⇒ longer wait (chart shifts right).
X ~ Geometric(p)

Probability Mass Function (PMF)

Probability that the first success occurs on the exactly k-th trial.

P(X = k) = (1−p)k−1 · p You need k−1 failures (prob. 1−p each) followed by one success (prob. p).
Enter a value for k (k ≥ 1) and click Calculate.

Cumulative Distribution Function (CDF)

Probability that the first success happens on or before the k-th trial.

P(X ≤ k) = 1 − (1−p)k (1−p)^k is the probability that you never succeeded in the first k trials.
Enter a value for k (k ≥ 1) and click Calculate CDF.
P(X ≤ k) = chance of getting your first success on or before the kth trial.
