Module 01 · Continuous distribution

Normal Distribution

Manufacturing Quality Control — describe how product measurements vary around a target size.

Quality engineering

Industry problem statement

A factory produces precision shafts with a target diameter of 10 mm. Small variations occur during manufacturing. The quality team wants to understand how measurements are distributed and estimate the proportion of shafts that meet the required size range.

Mathematical formula

f(x) = 1/(σ√(2π)) · e−(x−μ)²/(2σ²)

μ = mean · σ = standard deviation · x = measured shaft diameter

Module 02 · Continuous distribution

Exponential Distribution

Cloud Request Inter-arrival Time — model the waiting time between consecutive incoming requests.

Cloud computing

Industry problem statement

A cloud application receives requests from users throughout the day. This module models the time gap between consecutive incoming requests so that the team can understand request traffic and plan capacity. The illustrative arrival rate is 12 requests per minute.

Model assumption: requests follow a constant-rate Poisson arrival process. The exponential distribution describes inter-arrival time; it is not the same as server response time.

Mathematical formulas

f(t) = λe−λt,   P(T ≤ t) = 1 − e−λt
P(T > t) = e−λt
P(T > t₂ | T > t₁) = e−λ(t₂−t₁)

Convert λ to requests per second (λ/60) before using time in seconds. Mean = 1/λ and variance = 1/λ² in consistent units.

Input parameters

Change the arrival rate and waiting-time thresholds. Results and the curve update automatically.

More than t seconds—P(T > t)

Unit conversion: λseconds = λminute/60 requests per second. Mean = 1/λseconds s; variance = 1/λseconds² s²; density is measured in 1/s.

Memoryless property

For an exponential waiting time, if no request has arrived yet, the distribution of the additional wait is the same as it was at the start. In simple terms, the time already waited does not change the probability of waiting longer. The conditional probability depends on the gap t₂ − t₁, not on t₁ itself.

Module 03 · Sampling distribution

Central Limit Theorem

Warehouse Processing Time — understand how sample averages behave when many orders are processed.

Warehouse analytics

Industry problem statement

A warehouse processes customer orders, and the time required for each order can vary. A manager records processing times for groups of orders and studies their average. The Central Limit Theorem helps explain why averages from larger random samples tend to form a more predictable, approximately normal distribution.

Mathematical formula

μx̄ = μ,   σx̄ = σ/√n
X̄ ≈ N(μ, σ²/n)   for sufficiently large n

μ = population mean · σ = population standard deviation · n = sample size · X̄ = sample mean

Interpretation of results

The sample mean is centred around the population mean. As sample size increases, the standard error becomes smaller, so sample averages tend to vary less. This helps warehouse managers estimate average processing time more consistently.
